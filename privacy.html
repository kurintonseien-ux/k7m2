プライバシーポリシー

Personal Tool ／ 制定日 2026年11月7日

取得する情報

Google アカウントで許可したユーザー自身のアカウントについて、許可された範囲の統計レポートを Google の API から読み取ります。それ以外の情報は取得しません。

使い方

読み取ったレポートは、許可したユーザー自身のパソコンにファイルとして保存し、個人的な記録にだけ使います。

保存する場所

読み取ったデータと認証情報（OAuth トークン）は、このツールを動かしているパソコンにだけ保存します。開発者や第三者のサーバーには送りません。

第三者への提供

読み取ったデータを第三者に提供・販売・転送することはありません。広告にも使いません。

削除とアクセスの取り消し

Google アカウントの サードパーティのアクセス から、いつでもこのツールのアクセスを取り消せます。パソコン上の保存ファイルと認証情報のファイルを削除すれば、保存したデータも消えます。

Google API サービスのユーザーデータに関するポリシー

このツールが Google API から受け取った情報の使用と転送は、限定使用の要件を含む Google API サービスのユーザーデータに関するポリシー に従います。

改定とお問い合わせ

このポリシーを変更するときは、このページを更新します。お問い合わせは、このページを公開している GitHub リポジトリの Issues にお寄せください。

Privacy Policy

Personal Tool / Effective November 7, 2026

Data accessed

For the account of the user who authorizes it with their Google account, the tool reads statistical reports within the granted scope through Google APIs. No other data is accessed.

How the data is used

The reports are saved as files on the authorizing user's own computer and used only for personal records.

Storage

The data and the authorization credentials (OAuth token) are stored only on the computer that runs the tool. They are never sent to the developer's or any third party's servers.

Sharing

The data is never shared with, sold to, or transferred to third parties, and is never used for advertising.

Deletion and revocation

You can revoke the tool's access at any time from Third-party access in your Google Account. Deleting the saved files and the credential file on the computer removes the stored data.

Google API Services User Data Policy

The tool's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Changes and contact

Changes to this policy will be posted on this page. For questions, please open an issue in the GitHub repository that hosts this page.
